## 3. 主菜单三方案

### 方案 A — 现有素材轻量升级（最小）
纯黑底 → 深色渐变 + 地板平铺远景 + 2-3 只小怪剪影点缀 + 保持现菜单布局。
- 优点：1 天内完成、零风险
- 缺点：仍是"功能菜单感"，达不到"世界观第一秒"
- **评估：不够格**，不推荐作为独立交付

### 方案 B — 像素电影海报构图 ⭐ 推荐
三层景深 + 近大远小对峙构图（你给的草图方向）：

```
背景层  wall 平铺暗化(62%灰乘) → 纵深渐变(新封装,API现成)
        → 远处小怪剪影(4-6只, tile级 2-3×)
        → Boss 模糊暗影(boss_f10 @ 5-6×, tint 深灰+低α)
中景层  左:玩家阵营(player_fire/ice/poison 4-5×) + 武器延伸
        右:敌人方(mon_skeleton/shaman/orc 4-5×)
        建筑/门/火焰(kenney 拱门件+红罩光)
前景层  左右大剪影(近大 6-8×, 半出血裁切)
        中央: 标题金字(glow) + START/CONTINUE/SETTINGS
        径向 vignette(新写 ~20行)聚焦中央
```
- 优点：**风格绝对统一**（全 16×16 同源放大）、零新角色美术、程序手法 8 成现成、"世界观第一秒"达成
- 缺点：16×16 放大 6-8× 的巨像素块——**用构图层次（景深/裁切/暗化）让它们成为"海报元素"而非"贴图"**；排版需 2-3 轮实机调
- 工作量：TitleScene 重写渲染 ~200 行 + 渐变/vignette 封装 ~40 行
- **评估：推荐**——与项目"像素垂直切片"路线一脉相承

### 方案 C — 新增高清像素立绘（64/128×）
- 优点：最终效果天花板
- 缺点：17+ 角色立绘工作量大、破坏"现有素材即全部视觉"的统一管线、和 B 相比收益边际递减
- **评估：不推荐现阶段**——等 B 实机 Review 后若仍不满意再议
