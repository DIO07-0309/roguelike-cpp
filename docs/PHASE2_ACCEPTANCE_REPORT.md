## 二、逐项验收结论

### [1] Door 视觉是否成功 — ⚠️ 需人工确认视觉，结构已达标

**结构层面 ✅**：
- 每个 seed 地图均生成 Door tiles（14~22 扇）
- `<40% 的 Door` 位于房间边界外 1 格（WALL 圈内），不悬空
- 所有 Door 无越界（x,y 都在 1..W-2 / 1..H-2 内）
- 渲染实现：棕色方块 + 深棕描边 + 中心黄色圆点（`game_map.cpp` DOOR 分支）

**待确认**：实机画面中 Door（棕 + 黄点）是否与灰色墙、棕色地板有足够对比度。若混在一起，可能是颜色对比不足，具体由用户目测。

### [2] Room → Door → Corridor 空间感 — ✅ 结构验证通过

逐条断言全部通过（7 seed × 5 组）：
- **每个 Door 至少一侧邻接房间内部地板** ✅
- **每个 Door 至少一侧邻接走廊/开放区** ✅
- **每个 Door ≥2 个开放邻居**（不悬空）✅
- **房间中心、四角均为 FLOOR**（走廊未侵入房间）✅
- **所有房间从首个房间 BFS 可达** ✅

关键修正确认：`_carve_diamond()` 加了 `if (g[ty][tx] == '#')` 防护，走廊只雕刻墙壁、绝不修改已有房间地板（通过 `Rooms_Intact_AfterCorridor` 证明）。

### [3] 走廊体验 — ✅ 结构验证通过（含一处需关注点）

- 走廊不侵入房间 Interior ✅（房间中心/四角全为 FLOOR）
- 无断裂走廊 ✅（7 seed 全部 CONNECTED，BFS 可达 = 总 walkable 数）
- 走廊连接下一房间 ✅（所有房间可达）

#### 发现的关注点 ⚠️ —— 单个房间开口偏多

用**外围环墙体覆盖率**（房间外侧 1 格环形区域中墙的比例）客观测量房间封闭度：

| seed | 平均环墙覆盖率 | 最低 |
|------|:---:|:---:|
| 1  | 72% | 59% |
| 2  | 76% | 58% |
| 3  | 71% | **39%** |
| 42 | 78% | 68% |
| 100 | 77% | 59% |
| 999 | 77% | **50%** |
| 20240801 | 76% | 60% |

- **平均环墙覆盖率 71~78%**：房间基本被墙包裹，仅通过门开口，符合 Room→Door→Corridor 目标。
- **个别房间偏低**（seed 3 的 `room(3,9)` 仅 39%，seed 999 的 `room(23,16)` 仅 50%）：个别房间开口过多，视觉上可能感觉较开放。这是 BSP 固有差异，非系统性缺陷。

### [4] FOV + Door 组合体验 — ⚠️ 需人工确认

**结构层面 ✅**：
- Door 的 `blocks_sight = false`（默认开启状态），FOV 相关 8 个单测 + Door 拓扑测试全部通过
- `update_fov()` 与 Door tile 无兼容冲突

**⚠️ 潜在行为提示（用户需目测确认）**：
按设计，Door `blocks_sight=false` 意味着视线从门**透传**。玩家站在走廊/门口时，能透过门看到对面房间的更多内容。可能的表现：
- 玩家在走廊中提前看到下一个房间内部（视觉"泄楼"）
- 这目前是**设计如此**（开启的门不挡视线），Phase 2 不修改。

用户需实机确认：这种"透过门看到房间"的程度是否可接受。若过于突兀，可在后续 Phase（动态门）引入 CLOSED 状态的门遮挡视线。

### [5] 是否还有"一整片开放区域"的感觉 — ✅ 结构测量显示已明显改善

用**全局墙体密度**客观测量：

| seed | 墙体密度 |
|------|:---:|
| 1  | 43% |
| 2  | 43% |
| 3  | 41% |
| 42 | 52% |
| 100 | 46% |
| 999 | 42% |
| 20240801 | 44% |

- **墙体密度 41~52%**：属于健康的 dungeon 密度，约一半地图为可走区域，墙体有机地分割房间。
- **房间平均环墙覆盖率 71~78%**：房间是明显的"被墙包裹的空间，仅经门+走廊相连"，不再是连成一大片的开放区。
- **无巨型房间**（≥15×10 的 mega-room）在多数 seed 为 0（seed 3、20240801 各有 1 个，属正常波动）。

结论：**从头部（房间尺寸 + 起连通分量）看，"一整片开放区域"的观感已基本消除。** 最终感受请用户实机目测确认。
