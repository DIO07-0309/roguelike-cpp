# M4 · 500 局确定性基线 — 数据 Review

> 数据: `reports/m4_baseline_s{3,7,11,19,23}.json` (5 种子 × 100 局, 14.4s)
> 红线遵守: **只记录, 未改任何 AI/平衡参数**
> 意义: 这是仪表盘(M2)校准后的第一份多种子可信基线, 为 P1-A 排序提供依据

---

## 一、五个种子惊人一致 (数据本身的可信度证明)

| 种子 | 胜率 | 平均楼层 |
|---|---|---|
| 3 / 7 / 11 / 19 / 23 | 全部 0% | 全部 F1 |

**零方差不是 bug, 是发现**: SimAI 的失败与种子无关——是**系统性行为缺陷**, 不是运气或地图问题。M2-E 的确定性保证让这个结论可信 (同种子双跑字节级一致)。

## 二、核心事实 (SimAI 到底怎么死的)

1. **AI 从不拾取**: `picks=0.00` × 500 局。开局 2 瓶药水喝完 (369 局 heal>0) 后再无补给来源。
2. **AI 从不搜刮**: `gold=0`, `loot_wd=0` (搜刮看门狗从未触发 = 从未尝试搜刮路线)。
3. **武器恒空手**: `fist_basic 500/500`。F1 掉落的武器一次都没捡——`picks=0` 的直接后果, 攻击力永远 12。
4. **死因双头**: 被怪打死 62.4% (围殴空手玩家) + 毒 DOT 37.4% (史莱姆毒无法缓解——没药水)。
5. **卡墙高频**: 平均每局 9.4 次传送 / 348.8 次旋转脱困——**路径质量差是"没捡到东西"的上游原因**: AI 大概率根本走不到掉落物旁。
6. **DOT 死者 vs 围殴死者的画像差异**: 毒死的局平均 3101 帧 (快死), 被打死的局平均 6411 帧 (挣扎更久、卡墙更多 11.9 次)。两条死亡路径机制不同。
7. **房间探索 0.65/局**: F1 平均 2+ 特殊房只探了 1/3。
8. **1 局 TIMEOUT_WALL**: 36000 帧兜底, 归类正确 (仪表盘工作正常)。

## 三、归因链 (因果而非并列)

```
路径缺陷 (卡墙 9.4/局, 探索 33%)
   ↓
走不到掉落物 → picks=0, gold=0
   ↓
空手 + 无补给 (Lv1, HP120, ATK12)
   ↓
F1 双死路: 围殴 (62%) / 史莱姆毒 DOT (37%)
   ↓
100% F1 死亡, 0 通关
```

**结论: 这不是平衡问题, 是 P1-A 的 AI 行为问题。** 若现在调数值 (加强玩家/削弱怪) 是在掩盖 AI 缺陷; 若加"自动拾取补丁"是绕过路径根因。

## 四、P1-A 优先级建议 (供拍板, 顺序 = 因果链上游优先)

| # | 方向 | 依据 | 预期效果 |
|---|---|---|---|
| **A1** | **路径修复** (卡墙根因: BFS 直线冲刺的墙前震荡已有病理记录 P0-M2; 探索率 33%) | stuck 9.4/局是所有下游缺陷的上游 | picks/gold/rooms 直接改善 |
| A2 | 拾取决策 (掉落物在 BFS 途中即可拾取, 不需专门"拾取寻路") | picks=0 但药水补给是存活关键 | 死亡模式从"耗尽"转向"交战" |
| A3 | 毒对策 (血 <40% 且有毒时优先拉开/喝药) | DOT 37% + 毒死者局短 | DOT 死亡减半 |
| A4 | 武器意识 (地上有武器且空手时捡) | fist 500/500 | DPS 通道打开 |

**明确不推荐**: 现在调 F1 怪物数值; 现在做 MCTS/RL 强化 (决策质量不是瓶颈——AI 的技能/喝药决策框架都在, 是"走不到"让它死于补给)。

## 五、给 M5 (数据驱动美术) 的输入
