- M6 HD-2D 全线收官: 材质/地面/Arena 物件/Boss 氛围/角色资产/视觉收口

## 排序建议（交替节奏）

```
v1.5.0 tag → B1+B2 (小批热身, 兑现承诺) → A1+A2 (视觉速赢)
→ B3 (手感) → A3 (阴影) → 数据复盘决定 B4/B5 先后 → A4 → ...
```

## 待拍板决策点

1. **A5 角色动画**: 自研 2.5D 骨骼 vs 现成格式 (spine/oes 够不够用) — 涉及美术产能
2. **B3 翻滚**: 是否值得做 (动作游戏标配 vs 现有 0.5s 攻击间隔的手感定位) — **已拍板: 做, v1.7-B3 纯手感位移版** (无无敌帧/不改平衡, spec 存档)
3. **B6 无尽模式**: 是否符合 "15 层完整弧线" 的设计初衷
4. **双线并行 vs 单线推进**: 交替节奏是否适合单人产能
