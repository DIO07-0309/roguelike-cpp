# v1.6+ 双线路线规划（草案待拍板）

> v1.5.0 "HD-2D Demo" 发布后的走向。双线并行推进 v2.0。
> 本文档只列方向与排序建议，具体批次立项时再写实施计划。
> 原则: 每条线独立 Milestone 编号, 互不阻塞, 可交替开发。

## 现状基线（v1.5.0 出发点）

- M6 HD-2D 全线收官: 材质/地面/Arena 物件/Boss 氛围/角色资产/视觉收口
- 逻辑层零改动承诺全程保持 (SSOT + RNG 确定性红线未破)
- 已知技术债: 描边为 4 向偏移法非真轮廓; bloom 手调常量;
  实体不接收阴影; 雾对 LAVA 不生效

## Line A — 3D Art Line（视觉纵深）

> 目标: 从 "HD-2D" 走向完整 3D 表现力, 招牌卖相线。

| 批次 | 内容 | 依赖 | 预估 |
|:---|:---|:---|:---|
| A1 | 真轮廓描边 (后处理 edge-detect 或 depth-based) | M6-n 描边验证 | 中 |
| A2 | 环境粒子 (灰尘/萤火/岩浆浮尘, 群系配色) | ART_ASSET_PLAN 已列 | 小 |
| A3 | 实体接收阴影 (billboard 平面投影) | 光照系统 | 中 |
| A4 | bloom 逐帧亮度反馈 (HDR 替代手调常量) | A1 后 | 中 |
| A5 | 角色骨骼动画 (spine 式 2.5D, 替换 billboard 静帧) | 美术产能 | 大 |
| A6 | 摄像机语言 (Boss 战运镜/击杀顿帧推拉) | 全部就位后 | 中 |

红线: 逻辑层零改动; 性能不低于 60fps 基线; 每批过 M6 验证协议。

## Line B — Gameplay Line（玩法纵深）

> 目标: 兑现 "会学习你的 Roguelike" 承诺的深水区。

| 批次 | 内容 | 依赖 | 预估 |
|:---|:---|:---|:---|
| B1 | Mirror 记忆可视化升级 (战斗中实时展示它学到的你) | M1 已修回路 | 小 |
| B2 | 死因仪表盘游戏内化 (局外成长页显示你的死因谱) | M2 插桩 | 小 |
| B3 | 翻滚/闪避 (手感三件套 → 四件套) | 输入层 | 中 |
| B4 | 第 6 Boss (可选, 数据驱动 bosses.json 直接加) | 平衡报告 | 中 |
| B5 | Build 深度 (技能进化树扩展 + Build 专属镜像反应) | SKL_EVO 已有 | 大 |
| B6 | Endgame 挑战层 (F15 后无尽模式/每日种子) | 全部就位后 | 大 |

红线: 每批先跑 500 局基线对比 (M4 仪表盘); RNG 确定性红线不可破。

## 排序建议（交替节奏）

```
v1.5.0 tag → B1+B2 (小批热身, 兑现承诺) → A1+A2 (视觉速赢)
→ B3 (手感) → A3 (阴影) → 数据复盘决定 B4/B5 先后 → A4 → ...
```

## 待拍板决策点

1. **A5 角色动画**: 自研 2.5D 骨骼 vs 现成格式 (spine/oes 够不够用) — 涉及美术产能
2. **B3 翻滚**: 是否值得做 (动作游戏标配 vs 现有 0.5s 攻击间隔的手感定位)
3. **B6 无尽模式**: 是否符合 "15 层完整弧线" 的设计初衷
4. **双线并行 vs 单线推进**: 交替节奏是否适合单人产能
