# M4.4 序列记忆 (Sequence Memory) 设计

- 日期: 2026-08-07
- 版本: v0.9.23 (规划)
- 状态: 已批准
- 前序: M4.1-M4.3 战术层 + M5 条件维度 (v0.9.22)

## 目标

让镜像学习玩家的**动作序列套路**（连招模式），而非仅仅单步意图/状态桶。
玩家"攻击→闪避→攻击"这类节奏蕴含可预测信息；序列层补上第 3 阶门槛（N-gram），
不引入神经网络，保持完全可解释、可测试。

## 1. 组件: `SequencePatternTable` (组合，不继承)

独立新类，职责单一：从决策动作流学序列计数 → 预测下一步意图。

### 符号编码

- 粗符号 (主表键)：4 决策动作，取 `is_decision_action` 过滤后按时序串联
  - `ATTACK=0, SKILL=1, DODGE=2, HEAL=3`
- 细辅 (SKILL 下钻)：当后继是 SKILL 时，记录技能 ID 分布 (0=slash..3=the_world)

### 数据流

```
PlayerAction 流 (is_decision_action 过滤, 按 timestamp 升序)
  → 滑动窗口 3 → 主表 3-gram 计数: key = s0*16 + s1*4 + s2  (64 桶)
  → 若 s2==SKILL: 细辅表 (s0,s1) → skill_id 分布  (16 桶 × 4)
```

### 接口摘要（与 Male Clone 同构风格）

```cpp
struct SequencePrediction {
    PlayerIntention best = PlayerIntention::IDLE;
    float confidence = 0.0f;   // 最可能后继计数 / 该前缀总计数
    int   level = 0;           // 0=3gram, 1=2gram, 2=clone, 3=default
    int   predicted_skill_id = -1;  // 细辅下钻, <0=无
};

class SequencePatternTable {
public:
    void clear();
    void build(const std::vector<PlayerAction>& stream);
    void build_sequence(PlayerActionType a, PlayerActionType b,
                        PlayerActionType next, int next_skill_id);
    SequencePrediction predict(PlayerActionType s0, PlayerActionType s1) const;
    SequencePrediction predict_fuzzy2(PlayerActionType s0) const; // 2-gram 合并
    size_t entries() const;
private:
    std::unordered_map<int, int> _table3;        // 3-key -> 后继计数
    int _prefix_total[16] = {};                  // 每个 2-前缀 总次数 (置信度分母)
    int _s0_total[4] = {};                       // 每个单前缀总次数 (2-gram 分母)
    std::unordered_map<int, int[4]> _skill_tail; // (s0*4+s1) -> 技能分布
};
```

### 预测细节

- `predict(s0, s1)`: 查 `_table3` 中前缀 `(s0,s1)` 的 4 个后继计数 → 取 max。
  - level=0 (3-gram)，若最高后继计数为 0 → miss。
  - confidence = max_count / prefix_total。
- `predict_fuzzy2(s0)`: 合并所有以 s0 开头的前缀 → 后继分布 → level=1。
- 降级链: `predict` (3-gram) → `predict_fuzzy2` (2-gram) → clone (已有) → 规则兜底 (已有)。
- 细辅: 当 best==SKILL 时, 查 `_skill_tail[s0*4+s1]` 最高技能, 填 `predicted_skill_id`。

### 阈值/验收

- 3-gram 只在 `prefix_total >= 3` 且 `confidence >= 0.5` 时可信。
- 2-gram 只在 `s0_total >= 5` 且 confidence >= 0.5 时可信。
- 低于阈值一律降级，保证数据不足时保守。

## 2. 集成到 MirrorAgent (组合)

- `MirrorAgent` 持有 `std::unique_ptr<SequencePatternTable> _sequence;`
- `MirrorAgent#set_sequence_table()` 镜像 `set_clone_table()`
- `observe_actual()` 维护最近 2 个粗符号环形缓冲 `_seq_a, _seq_b`
- 新增 `predict_sequence()` 内部链路:
  ```
  _seq->predict(_seq_a, _seq_b)   // 若 level<=1 且 confidence>=门槛
      → 克隆表 (level 2)
      → 规则兜底
  ```
- 仲裁优先级: **ML 槽 → 序列层(3/2-gram) → 克隆层 → Thompson**
- 漂移降权复用 `clone_confidence_threshold()`: 玩家换打法时序列降权，
  交 Thompson 在线适应。
- F15 enter 时与克隆表同步 build (离线)。
