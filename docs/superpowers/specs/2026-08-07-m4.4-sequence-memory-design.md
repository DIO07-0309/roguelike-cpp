# M4.4 Tactical Sequence Memory (战术链序列记忆) 设计

- 日期: 2026-08-07
- 版本: v0.9.23 (规划)
- 状态: 已批准 (v2 — 用户验收 M4.1 后重定向)
- 前序: M4.1 三场景验证通过 (v0.9.22+), M5 条件维度 (v0.9.22)

## 目标

让镜像学习玩家的**战术动作序列套路**（战术链），而非"玩家风格镜像"的频率统计。
战术链 = 技能→位移→武器→连招 的 2-4 步序列模式。
与 M4.1 的 if-else 战术决策不同：本层是**数据驱动的序列学习**，不再堆 if-else。

## 1. 采集层扩展 (前置依赖)

`PlayerAction` 已含: skill_id, value(位移方向), facing_dir, hit_in_1s, weapon_name。
**缺 2 个字段**，需补:

```cpp
int weapon_type = -1;   // WeaponType 枚举 int, -1=未知 (非ATTACK动作)
int combo_stage = -1;   // 0/1/2 连招段 (第1/2/3段), -1=未知
```

填充点: `weapon_executor.cpp:221` 调 `on_weapon_attack()` 处已有
`stage_before` (连招段) 与 `def->type` (武器类型)，扩展签名传入。

## 2. 组件: `TacticalChainTable` (组合，新类)

与 `BehaviorCloneTable` 同构 (n-gram 计数 + 降级链)，但符号空间不同。

### 符号编码 (战术动作)

从 PlayerAction 映射为战术符号 (int)：

| 符号 | 来源 | 说明 |
|---|---|---|
| 0-3 | SKILL + skill_id | 玩家放技能 (slash/fireball/self_heal/the_world) |
| 4-7 | MOVE + value | 位移 (0=左,1=右,2=上,3=下) |
| 8-11 | ATTACK + combo_stage | 连招段 1/2/3 |
| 12 | ATTACK + combo_stage=0 | 连招新循环起点 |

符号空间 13 个 → 3-gram 空间 13³ ≈ 2197 桶。
数据密度: 单局 550 动作, 决策子集 ~200-300 → 3-gram 稀疏但 2-gram (169) 可行。
**降级链: 3-gram → 2-gram → 克隆表 → 规则** (与现有链一致)。

### 预测语义

给定玩家最近 2 个战术符号 → 预测第 3 个 (最可能战术动作)。
输出 PlayerIntention + 战术链 context (skill_id/combo/weapon)，供镜像选应对臂。

## 3. 集成到 MirrorAgent

- 持有 `std::unique_ptr<TacticalChainTable> _chain;`
- `observe_actual()` 维护最近 2 个战术符号缓冲 (环形)
- 仲裁优先级: **ML 槽 → 战术链(3-gram→2-gram) → 克隆表 → Thompson**
- F15 enter 时与克隆表同步 build (离线)
- 漂移降权复用 `clone_confidence_threshold()`

## 4. 明确不做 (YAGNI)

- 不做在线滚动更新
