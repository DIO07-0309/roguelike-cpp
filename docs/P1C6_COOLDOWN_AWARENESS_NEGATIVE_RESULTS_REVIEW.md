## 三、病理分析 (每版负回归的真因)

### 3.1 v1 族 (ε 全让渡): 生存↑输出↓ 的结构性置换

- 挨打窗口（冷却期）全部让渡给撤退 0.6/喝药/拾取 1.6 → AI 变"怂"
- 证据链: dmg -12% + **taken -11% + heal -34%** 同源；run1 基线 F9
  莽死 1469dmg → v1 F6 卡超时 975dmg（活得久但输出塌）
- **基线的 d3=77% 站桩不是纯病理 — 它是"最大化输出姿态"**：
  圈边持续按攻击使冷却流转 + 怪进 48px 瞬间命中（C5 已证），
  挨打换输出是当前 6% 胜率构筑的隐性平衡成分

### 3.2 v1.3/v1.4 (比例衰减): 捡逃死循环

- 30%/50% 衰减后冷却期攻击分 0.21~0.39 < 拾取 1.6 / 残血撤退 0.6
- 持械残局进入"捡东西→逃→被围→传送→再捡"循环，零出手磨死
- run9 实录: 3 次口袋传送 + picks=16 + dmg=0
- **步进门与衰减叠加放大**: v1.4 (1.40) vs v1.4a (4.45) — 步进 0.25
  在围殴局把贴脸就位变成送头，单怪门挡不住多怪房

### 3.3 C4PROBE 分布变化的正确解读

四版共同特征 d2 (50-75%) 22%→43~80%: AI 大量时间处于 24-36px 走位中。
**d3 降 ≠ 出手率升** — 决策分布位移了，但 48px→32px 的走位窗口里
出手时机被移动帧稀释，命中密度未提升（dmg 全线下降为证）。

## 四、新发现 (记入下批输入)

1. **双轨攻击判定**: 空手走 legacy `Player::can_attack` (0.5s CD)，
   持械走 `WeaponComponent::can_attack` (0.15s) — `_evaluate_attack`
   若消费武器冷却感知，空手局判定语义错轨（v1.3 F1 全灭放大器之一）
2. **特殊攻击窗口**: nunchaku/spear 的 `sp.active` 期间 `can_act()=false`
   但伤害进行中 — 冷却感知必须排除（v1.1 已加门，冒烟未命中但理论成立）
3. **混沌分岔传播**: 同 seed 冒烟下 run0-2 可与基线逐字节一致、run3 起
   分岔 — **跨 run 的世界状态无隔离**（同进程串行 20 局，前一局行为
   改变必然传播）。单局对比无效，只看 20 局聚合 + 首分岔 run 定位法
   （本次新增方法论：`[SIM] N%` 行做 run 边界对齐）
