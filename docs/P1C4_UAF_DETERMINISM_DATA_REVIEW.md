## 一、UAF 根治 (本批核心成果)

### 1.1 症状
同 exe 同 seed 同参数 20 局冒烟, 结果在两种形态间随机切换:
- 形态 A: n=100 (attack-eval 采样), avg_floor=6.65, F1 死 2/20
- 形态 B: n=118, avg_floor=6.25, F1 死 10/20 — **胜负级差异**

P1-C3 曾用 MD5 验证"同 seed 双跑一致"并以此背书确定性 — 该验证
恰好两次落在同一形态, 假阳性通过。**教训: 间歇性缺陷需要 N≥4 次重复**。

### 1.2 定位过程 (探针逐层收网, 每层一个可证伪假设)
1. 传送指纹 (帧号+RNG draws+坐标): 504 次传送完全一致, 第 505 次分岔
   → 排除传送/RNG/寻路, 分岔在两次传送之间 ~780 帧的"无日志区间"
2. 帧级 FPDIAG (每 3 帧: HP+位置+RNG draws+怪名/hp/坐标): 收窄到
   f=616656 → 616659 之间, 兽人 hp84 之死处理不同
3. KILLDIAG (击杀时 rng 指纹): A kill@f=616658 rng=71295 (多 52 抽 =
   武器攻击链), B kill@f=616656 rng=71243 (零消耗) — 死法不同
4. FPDIAG 加 time_stop_remaining + pending_damage 数量: f=616656
   两进程 ts=0.017 pd=2 **完全一致** → 锁定时停结束结算
5. PENDDIAG (挂起伤害目标+地址+valid 匹配): **A pd 指向活兽人,
   B pd 是 DANGLING 悬空指针** — 84 伤害凭空丢失 → 兽人不死 →
   AI 看到不同世界 → 全链分岔

### 1.3 根因
`pending_damage` 存**裸 Monster\***。时停期间目标怪被 cleanup/kill
路径 erase 释放, 指针悬空。时停结束 `_apply_pending_damage` 的 valid
检查 (在 monsters 中按地址匹配):
- 常规失效 → 伤害直接丢失 (本例: 兽人本应死于时停挂起伤害)
- 堆地址被新怪复用 → valid 检查被欺骗 → **伤害打到错误的怪身上**

是否触发取决于**进程堆布局 (Windows ASLR)** — 纯运行期运气,
与游戏逻辑无关。500 局中每当局内有 TheWorld 时停 build 时,
结局在两种世界线间随机分裂。

### 1.4 修复
| # | 改动 | 文件 |
|---|---|---|
| 1 | `pending_damage` 类型 `pair<Monster*,int>` → `pair<uint64_t,int>` (instance_id) | game_scene.h |
| 2 | 结算按 id 在 monsters 中查找, id 不存在/怪已死 → 诚实跳过 | game_scene_combat.cpp |
| 3 | push 点 ×3 改存 instance_id | player_controller / combat_coordinator |
| 4 | 删除死代码 `CombatCoordinator::apply_pending_damage` (零调用者+UAF 语义) | combat_coordinator.{h,cpp} |

### 1.5 验证
- 同 seed 8 连跑 MD5 全一致 (修复前 ~50% 概率分岔)
- s7 4 连跑一致; 5 种子×100 局全部 exit=0
- **历史所有 500 局对比数据中含时停局的方差部分被本缺陷污染,
  P1-C4 起的对比基线才是干净的**

## 二、贴脸拉开分 0.9→0.6 (SimAI)

P1-C3 数据: 270 局 F1 围殴死 100% 零杀, avg 118s 仅 1.65dps。
根因: 危急撤退 `bfs_away` 得 0.9 分持续压过贴脸攻击 (d0≈0.67),
AI 全程逃命被追着咬。0.6 保留撤离意图但让贴脸攻击反超 →
"逃一步打一下"轮换。500 局验证无回归 (F1 死亡率 90.2%→91.0% 持平,
未见"逃命死锁"复发 — stuck_tp 12.2/局 与基线同量级)。

## 三、C4PROBE: F1 围殴死亡的真因定位

攻击评分命中时的最近怪距离分布 (n=118, 3s 采样):

```
d0 (0-32px)  = 17.8%   ← 稳定出手区
d1 (32-48px) = 82.2%   ← 边缘圈! 怪挪 1px 即出攻击半径
d2+          = 0%
```

**82.2% 的攻击决策发生在"攻击圈边缘"** — 与 P1-A4 探针结论
(60 冷却拦截 vs 3 命中) 互证: AI 停在 32-48px 时攻击评分非零但
实际出手被冷却/半径抖动吞掉, 表现为"看得见打不着"的站桩磨死。
这是 **P1-C5 的接力信号: 贴脸步进泛化** (P1-A4 的步进只对
FIST 生效, 且阈值 32px 太紧 — 需要 d≤0.8 格的 hysteresis 或
攻击半径判定与决策半径对齐)。
